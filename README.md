# C++ Learning Projects Collection (2016-2017)

A collection of C++ projects developed during my early programming education, demonstrating fundamental concepts in object-oriented programming, data structures, algorithms, and parallel computing.

## 📋 Projects Overview

### 1. File Mover
A Windows-based file management utility that provides error-handling for file operations.
- **Technologies**: Windows API, C++ Exception Handling
- **Key Features**: File system operations, error reporting

### 2. Intelligent House Simulator
An object-oriented simulation of a smart home climate control system with multiple rooms and air conditioning units.
- **Technologies**: C++, OOP Design Patterns
- **Key Features**: Temperature control, room management, real-time simulation

### 3. MasterMind Game
A console implementation of the classic code-breaking game with color-based puzzles.
- **Technologies**: C++ STL, Game Logic
- **Key Features**: Random code generation, hint system, user input validation

### 4. Personal Planner
A command-line event management application with sorting and scheduling capabilities.
- **Technologies**: C++ STL (vectors, algorithms), lambda functions
- **Key Features**: Event scheduling, sorting, date/time validation

### 5. Parallel Quicksort Algorithms
Implementation and comparison of various quicksort algorithms including sequential and parallel versions.
- **Technologies**: MPI (Message Passing Interface), OpenMP
- **Key Features**: Parallel sorting, performance benchmarking, distributed computing

### 6. Simple Matrix Calculator
A console-based matrix calculator supporting basic linear algebra operations.
- **Technologies**: C++ OOP, Dynamic Memory Management
- **Key Features**: Matrix operations (addition, subtraction, multiplication), dynamic memory allocation

## 🛠️ Technologies & Concepts Demonstrated

- **Object-Oriented Programming**: Classes, inheritance, encapsulation
- **C++ STL**: Vectors, algorithms, iterators
- **Memory Management**: Dynamic allocation, proper cleanup
- **Parallel Computing**: MPI, OpenMP
- **Windows API**: File operations, system calls
- **Error Handling**: Try-catch blocks, error reporting
- **Modern C++ Features**: Lambda functions, auto keyword, range-based loops
